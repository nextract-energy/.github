## Labels

Select one (and make sure your PR title starts with it):

- [ ] 🟢 config – only config / CI changes
- [ ] 🟡 refactor – structural, no logic changes
- [ ] 🟠 logic – business logic changed
- [ ] 🔴 security – auth/permissions/security-critical
- [ ] 🔴 bug – urgent fix

## Dependencies

If there are multiple PRs across repos that belong to the same topic, please mention it here, for example:

- depends \<service-name>
- depends \<service-name-2>
